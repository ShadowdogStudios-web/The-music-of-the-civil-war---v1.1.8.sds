# The Music of the War — GitHub Pages

This folder is a complete static website. Its entry point is `index.html`, which
links to the student activity at `interrogate-the-anthem.html`. Images and audio
are in `assets/`; upload the entire folder contents, including `assets/`.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload **the contents of this folder** into the repository root (the two HTML
   files, `assets/`, `.nojekyll`, and optionally this README). GitHub's website
   may hide `.nojekyll` in some upload workflows; these pages also work without it.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**,
   choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Open the Pages URL shown in Settings → Pages after publishing finishes.

The student page is available at `<your Pages URL>/interrogate-the-anthem.html`.
The activity saves answers in the browser and allows students to download or
restore their work. Browser storage remains local to the student's device.
